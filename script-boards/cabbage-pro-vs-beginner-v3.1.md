### 🌾 1-B：謎フック

なぜ、こんなに差がつくのか。

不思議じゃないですか？

同じ品種、同じ日に植えて、同じ畑のすぐ近くで育ててるのに、

片方は1.5キロ、もう片方は500グラム。

3倍以上違う。

それはね、

プロの畑と初心者の畑に、

**決定的な違いが3つ** あるからなんです。

たった3つ。

しかも、その3つは、特別な技術でも、特別な道具でもありません。

実は、これ、

プロが当たり前にやってる、

でも初心者は知らないままやってしまう、

そんな違いです。

家庭菜園で初めてキャベツを作る方、

何年か作ってるけど結果が安定しない方、

あるいは、これから本格的に農業を始めようとしている方。

その全部に、当てはまる話です。

逆に言うと、

この3つを知らないままだと、

毎年、500グラムのキャベツしか作れない。

3倍違う1.5キロのキャベツを作るには、

この3つを知って、実行するしかありません。

ここで、 ひとつ質問させてください。

「キャベツの作目入口」 として今日の動画があって、

日付。スケジュール管理。

日々の管理。

3倍ですよ。

家庭菜園で1.5キロのキャベツを作るのと、500グラムしか作れないのは、

この3つの差なんです。

このあと、1つずつ深掘りしていきます。

聞き終わったら、

土も作れてない、

「なんで他の農家さんは普通に作れてるのに、自分は…」

毎年悩みながら、ひとつずつ理解して、

「あ、これが分かってなかったんだ」って、

気づきながら、ここまで来ました。

なので、今日の話は、

プロが偉い、初心者がダメ、っていう話じゃありません。

僕も、最初は初心者でした。

ただ、知ってると知らないでは、結果が全然違う。

ここを押さえれば、

初心者の方でも、

確実に、プロの畑に近づけます。

## 🆕 章2：違い①「土を作っているか」（畑撮影・約5:30）

### 🌾 2-A：違い① タイトル

**画面：** 畑にイチロウ立ち位置・視聴者に正面

それじゃ、いきます。

**決定的な違い、1つめ。**

**「土を作っているか」**

ここがプロと初心者を分ける、

最初の、そして最大のポイントです。

なぜ「最大」かというと、

ここを外すと、その後の何をやっても、上に積み上がらないからです。

逆に、ここが整ってると、

その後の管理が多少甘くても、それなりの結果が出る。

それくらい、土が全部の土台になっています。

土って、見た目は同じに見えるけど、

中身が全然違うんです。

家庭菜園で「あれ、なんかうまく育たない」って思った方、

おそらく原因の半分以上が、ここにあります。

肥料を増やしても、水をたっぷりやっても、

土ができてないと、なかなか育たない。

そういう経験、ありませんか？

→ 編集挿入: 「違い① 土を作っているか」見出しスライド
→ 編集挿入: 良い土と痩せた土の比較イラスト（いらすとや）

### 🌾 2-B：地力窒素とは

土を作る、

その中心にあるのが、

**地力窒素（ちりょくちっそ）** という考え方です。

土の中の有機物から、

時間をかけて、ゆっくり出てくる窒素のこと。

肥料袋から「ドバッ」と入れる窒素じゃなくて、

土自体が持ってる栄養の蓄えです。

この地力窒素が、

ちゃんと畑にあるかどうか、

ここが、プロと初心者の最初の分かれ道です。

→ 編集挿入: 「地力窒素」概念図（土の中で有機物が分解されて窒素になる流れ）

### 🌾 2-C：土づくり3つの柱

**画面：** 畑にイチロウ立ち位置・視聴者に正面

僕が現実的に、

地力を作るためにやってきたのは、

シンプルです。3つだけ。

**1つめ、牛糞堆肥。**

これをしっかり、畑に入れる。

「しっかり」っていうのは、

そこそこ多めに、ということです。

**2つめ、緑肥。**

夏に蒔いた緑肥を、

きちんとすき込んで、土に還す。

これも、地力を作るうえで、

すごく役に立ってきました。

緑肥のお話は別の動画でも詳しくやってますので、

そっちも観てみてください。

**3つめ、元肥。**

牛糞堆肥や緑肥で土の地力を整えたうえで、

植える前に、**元肥を絶対しっかり入れる。**

ここを省略する初心者の方、

けっこういます。

「土が良ければ肥料いらないんじゃ」って思って、

元肥を省略しちゃう。

でも、これがないと、

スタート時点で、もう遅れてるんです。

→ 編集挿入: 牛糞堆肥のいらすとや（袋／散布イメージ）
→ 編集挿入: 緑肥のいらすとや（ソルゴーすき込みイメージ）
→ 編集挿入: 元肥のいらすとや（肥料を畝に入れるイメージ）
→ 編集挿入: 「①牛糞堆肥 ②緑肥 ③元肥」3本柱スライド

### 🌾 2-D：補給手段の全体像

ここで、補給手段の全体像を整理しておきます。

シンプルに、確実に成功させるなら、

**化成肥料、液肥、追肥、堆肥。**

この4つを、状況に応じて使い分けていく。

これがプロの考え方です。

→ 編集挿入: 4種類の肥料一覧（化成・液肥・追肥・堆肥の比較スライド）

具体的にお伝えすると、

**元肥は絶対いる。**

**追肥もきちっとやる。**

**足りなければ液肥をやれる判断を持つ。**

**そして、それより前に、堆肥をきちんと入れておく。**

この順番で組み立てます。

順番が大事です。

→ 編集挿入: 「堆肥 → 元肥 → 追肥 → 液肥」順番フローチャート

### 🌾 2-E：足りてないサインは分かりにくい

**画面：** 畑にイチロウ立ち位置・視聴者に正面

ここで、よく聞かれる質問。

「地力窒素が足りてない畑のサインは何ですか？」

正直に言いますね。

**これは、分かりにくいです。**

土を見ても、手触りでも、

ぱっと「足りてない」って判断するのは、難しいんですよ。

僕も、16年やってきて、

土を握っただけで「これは足りてる」って言える境地には、

正直、まだ達してません。

熟練の農家さんでも、

「ここは足りてる、ここは足りない」って完全に分かる人は、

そんなに多くないと思います。

→ 編集挿入: 土を手に取るいらすとや or プロの土診断イメージ

### 🌾 2-F：1作目の判断

例えば、

プロが今まで使ってた畑なら、

地力が足りてる可能性は、高い。

長年、堆肥を入れ続けてきた畑には、蓄積があります。

でも、新しい畑、

家庭菜園を始めたばかりの土地は、

正直、最初の1作は作ってみるしかない。

僕が言っている通り、

堆肥をしっかり入れて、

元肥もしっかり入れて、

それで作ってみる。

それで、

理想通りにできれば、地力は足りていた、

できなければ、足りていなかった、

ということです。

最初の1年は、答え合わせの年。

そう思って、思い切って投資して試してください。

→ 編集挿入: 「1年目＝答え合わせ」コンセプトスライド

### 🌾 2-G：プロは「投資する」

**画面：** 畑にイチロウ立ち位置・視聴者に正面

ここがね、

プロと初心者を分ける、

**いちばん大きな考え方の違い** かもしれません。

プロは、

最初から、しっかりと、

土に「投資」するんです。

堆肥のお金。

肥料のお金。

そして、時間。

「もったいない」じゃなくて、

「ここは絶対やる」って、

最初から決めてる。

なぜかというと、

ここをケチると、その先の手間が3倍、5倍に増えるから。

「最初に投資する方が、結局安く済む」って、

16年やって、痛感してます。

→ 編集挿入: 「投資する vs ケチる」コスト比較イラスト（いらすとや）
→ 編集挿入: 中川農産の堆肥・肥料投入実績の写真（あれば）

### 🌾 2-H：面積とリスクの考え方

ただし、

ここで救いになるのが、

**面積の話** です。

面積が広いと、投資金額が大きくなって、

外したときのリスクもデカい。

でも、家庭菜園レベルで、

面積が狭ければ、

そのリスクは抑えられます。

「ちょっと多めかな？」くらい入れても、

家庭菜園の規模なら、お財布的にもダメージは少ない。

ここは、

初心者の方こそ、思い切ってやってほしいポイントです。

数千円ケチって失敗するより、

数千円多めに使って、最初から良い結果を出す。

その方が、来年・再来年、確実に育つ畑になっていきます。

→ 編集挿入: 大きい畑と小さい畑の対比イラスト（いらすとや）

## 🆕 章3：違い②「苗の植え付け日付を守る」（畑撮影・約4:30）

### 🌾 3-A：違い② タイトル

**画面：** 畑にイチロウ立ち位置・視聴者に正面

それじゃ、2つめにいきます。

**決定的な違い、2つめ。**

**「苗の植え付け日付を守っているか」**

これがね、

地味に、けっこう、

プロと初心者を分けます。

数字でいうと、たった1週間の差。

でも、結果は天と地ほど変わるんです。

「日付を守る」って、すごく地味な話なんですよ。

「いや、当たり前じゃないか」って思うかもしれません。

でも、地味に思えるからこそ、

多くの初心者の方が「まあ、ちょっとくらい遅れても」って、

軽く考えてしまうんです。

ここが守れないだけで、

その先の苦労が、全部空回りになる。

土をしっかり作っても、

管理を頑張っても、

日付がズレてたら、結果が出ない。

そういうポイントです。

「地味だけど、外せない」、

これが2つめの違いです。

→ 編集挿入: 「違い② 日付を守っているか」見出しスライド
→ 編集挿入: カレンダーいらすとや（日付を意識するイメージ）

### 🌾 3-B：品種ごとの日付

キャベツって、

品種ごとに、

**種を蒔く日が、ほぼ決まってる** んです。

「いつ蒔いてもいい」じゃないんです。

その品種、その地域、

それぞれに「この日に蒔く」っていう、

逆算された日付がある。

種の袋にも書いてあるし、

種苗店で聞けば教えてくれます。

その日付を、ちゃんと守る。

これがスタートです。

→ 編集挿入: 種袋いらすとや＋カレンダー
→ 編集挿入: 品種別 種まき日 早見表スライド（簡易版）

### 🌾 3-C：種まきから25-30日

そして、

種を蒔いてから、

**25日から30日後** に、

苗を畑に植える。

これも、品種で多少前後しますが、

おおよそ4週間前後がベース。

ここから、秋の収穫までのスケジュールが、

ぜんぶ繋がってるんです。

→ 編集挿入: 「種まき → 25〜30日 → 苗植え」タイムラインスライド

### 🌾 3-D：スケジュールは1本の線

**画面：** 畑の畝を歩きながら／視聴者に正面で話す

つまり、

種まき、植え付け、追肥、収穫、

これ全部、

**1本の線になってる** んです。

どこか1つの日付がズレると、

その先のスケジュール、全部ズレます。

カードゲームでいう、ドミノ倒し。

最初の1枚が倒れると、最後まで全部倒れる、そんな感じです。

種まきが1週間遅れたら、

苗植えも1週間遅れる、

追肥も1週間遅れる、

収穫も1週間遅れる、

全部が後ろにズレていく。

→ 編集挿入: ドミノ倒しのいらすとや or 「種まき→植付→追肥→収穫」横一直線タイムライン
→ 編集挿入: 「1週間ズレた場合」赤線でズレを可視化したスライド

### 🌾 3-E：1週間ズレるとどうなる

**画面：** 畑にイチロウ立ち位置・視聴者に正面

ここが、

僕が16年やってきて、いちばん伝えたいところです。

**苗の植え付けが、1週間ズレる。**

これ、

「ちょっと遅れただけ」じゃないんです。

**もう、収穫できないレベル** で、

結果が変わると思ってください。

実際、僕の畑でも、

同じ品種で1週間遅らせて植えた経験があります。

結球の大きさが、半分以下になりました。

それくらい違うんです。

なぜそんなに変わるかというと、

キャベツが結球するまでに必要な「気温・日照・期間」、

これが季節とぴったり合うように、

種まき日付が逆算されてるからなんです。

だから、1週間ズラすと、

その期間が「気温が下がりすぎ」「日照が足りなさすぎ」になって、

結球が完成しない。

→ 編集挿入: 「予定日 vs 1週間遅れ」結球サイズ比較画像（実績写真 or いらすとや）
→ 編集挿入: 「気温・日照・期間」3要素スライド

### 🌾 3-F：サイズ目安（畝間が埋まる）

「順調に育ってるか」の見極めも、

シンプルです。

サイズの目安は、

**畝の間（うねま）が、しっかり埋まってくる** こと。

葉が、ぎっしり広がって、

畝間が見えなくなるくらいまで育てば、

順調に進んでます。

逆に、
